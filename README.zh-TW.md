# BRICK MUSOU(積木無雙)

[English](README.md) | **繁體中文** | [日本語](README.ja.md)

**▶ 立即遊玩:<https://brick.akiraxclaw.com>**(備用:<https://brick-warriors.vercel.app>)

![BRICK MUSOU](assets/og.jpg)

用 **Three.js** 打造的**積木風格三國無雙割草動作遊戲**,整個遊戲只有**一個 HTML 檔**。
武將與敵將使用內嵌在網頁裡的 **LDraw 真實積木零件**;雜兵、武器、馬匹、場景、動畫、特效、後處理、
音樂與音效全部由程式即時生成,沒有任何圖片、模型或音訊檔。

- 同屏最多 **140 名積木兵**,全速割草時每分鐘擊破 200 人以上
- **三關戰役**、**無盡之陣**、全世界同一天打同一場的**每日挑戰**
- **4 名可操作武將**,每人 36 招,各有專屬無雙
- 支援鍵盤、**手把**、**觸控**(多點觸控虛擬搖桿)
- 英文 / 繁體中文,可在設定中隨時切換

> 積木小人本來就是剛體:不彎肘膝、肩髖單軸擺動。這和遊戲原有的姿勢系統完全同構,
> 所以 36 招連段、空戰、格擋、騎乘等全部戰鬥系統一行未改就直接沿用。

## 快速開始

- **線上遊玩**:<https://brick.akiraxclaw.com>
- **本機執行**:直接用瀏覽器打開 `index.html`,或啟動本地伺服器:

```bash
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。Three.js r160 由 CDN 載入,需要網路連線。
排行榜需要 Vercel 後端(見[線上排行榜與數據](#線上排行榜與數據)),沒有後端時會顯示「尚未開放」。

## 戰役 ── 第一章:反董卓聯合軍

主選單「出陣」→ **戰役地圖** → 選將 → 戰前簡報 → 開戰。每場戰役有自己的場景、天色、敵將、配樂與任務目標。
完成 **◆ 主要目標**即勝利,每完成一項 **◇ 次要目標**都會提高評價。通關後解鎖下一戰。

| 戰役 | 場景 | 主要目標 | 次要目標 | 敵將 |
|---|---|---|---|---|
| **汜水關之戰** | 晨間山隘,兩側峭壁 | 攻陷 2 座營寨 → 城門大開、**華雄出關** → 擊破華雄 | **溫酒斬華雄**(出關 60 秒內擊破)、攻陷全部營寨 | 華雄 |
| **虎牢關之戰** | 黃昏平原,兩翼大軍 | 擊破**呂布**(登場時城門推開) | 擊破胡軫、李肅,攻陷全部據點 | 胡軫、李肅、呂布 |
| **洛陽追擊戰** | 夜晚火城 | 在**董卓**逃出北門前擊破他(讓他逃走就算敗北) | 擊破徐榮、擊破 400 人 | 徐榮、董卓 |

- 汜水關與虎牢關一開始就開放,洛陽在通關虎牢關後解鎖。
- 虎牢關的劇情依**擊破數或時間推進,先到者算**:高手靠擊破提前推進,新手靠時間也能照常推進。
- 戰功評價(S/A/B/C)依擊破數、最大連擊、剩餘體力、用時、次要目標與難度加權計算,戰績依「關卡 × 難度」分別保存。

### 敵將招牌技

| 敵將 | 招牌技 | 對策 |
|---|---|---|
| 華雄 | **衝陣**:地面出現直線預警後高速衝鋒,途中霸體 | 看到預警就橫移 |
| 胡軫 | **喚弓兵齊射**:在你周圍落下 3 處箭雨 | 離開紅圈 |
| 李肅 | **反擊架勢**:你連打時舉起架勢(金色光點),這時打他會被無法格擋的迴旋反擊 | 看到架勢先停手 |
| 徐榮 | **伏兵煙幕**:在煙霧中後撤,並在你身邊召出 6 名伏兵 | 用無雙清場 |
| 呂布 | 跳劈(紅圈預警)、旋風斬、血量 35% 以下狂暴 | — |
| 董卓 | 往北門逃;被追上時停下反擊 5~7 秒(跳躍震地,不可格擋),再脫離繼續逃 | 疾走緊追、無雙爆發 |

洛陽另有**燃燒瓦礫**:紅圈預警 1.2 秒後落下,敵我都會受傷。

## 武將

| 武將 | 武器 | 特色 | 無雙 | 終結技 |
|---|---|---|---|---|
| 劉備(玄德) | 雌雄雙股劍 | 出招最快、連擊流暢,均衡型 | **雙龍亂舞**:向前突進(可轉向),雙劍左右交叉連斬,前方 210° 判定 | 躍起交叉斬,範圍 6.5 |
| 關羽(雲長) | 青龍偃月刀 | 攻擊範圍最大,大開大闔 | **青龍怒濤**:三次 360° 大橫掃,每圈都帶震波 | 過頂重劈,範圍 9 |
| 張飛(翼德) | 丈八蛇矛 | 威力最強,蓄力可裂地 | **燕人咆哮**:連續戳地,震波逐漸擴大,把整片敵人打上天 | 大地裂,範圍 11 |
| 呂布(奉先) | 方天畫戟 | 任一模式**擊破呂布即解鎖**;單騎出陣,不帶友軍 | **天下無雙**:可移動的畫戟旋風,每 0.9 秒震地一次 | 範圍 12 |

實測(兵海圍上來後發動):關羽一次無雙約 200 擊破、張飛約 190、劉備約 100。劉備是速度型,
無雙走「向前突進割草」而不是「原地清場」,擊破數刻意設定較低。

沒被選用的兩位會作為**友軍武將**一同出陣(綠色名牌、敵將級戰力)。倒下時單膝跪地 25 秒後重整旗鼓,
不會永久陣亡,但每次倒下士氣 −8。

## 遊戲模式

| 模式 | 說明 |
|---|---|
| **戰役** | 上述三場戰役。 |
| **快速出陣** | 用上一場的關卡、武將與難度直接開打。 |
| **無盡之陣** | 無限波次,每 40 秒一波,每波敵兵體力 +7%、攻擊 +5%;每 3 波一名敵將、每 6 波呂布再臨。撐到第 12 波評價 S。 |
| **每日挑戰** | 以日期為種子,**同一天全世界拿到同一位武將、同一難度、同一變異**,開場 48 名敵兵的配置也相同。會紀錄連續挑戰天數。 |

**每日變異**(每天抽一種):弓矢如雨(弓兵倍增)・鐵壁(敵兵體力 +35%)・血氣方剛(無雙計量 +70%)・
背水(體力 −40%、攻擊 +30%)・士氣低迷(據點不再影響士氣)。

> 每日挑戰**不保證逐幀一致**:同屏敵兵上限會依裝置效能升降,手機和桌機本來就打不到完全同一場。
> 固定的是武將、難度、變異與開場配置。

## 成長與收集

- **武將等級 Lv1~20**:親手擊破得經驗(雜兵 1、敵將 25、BOSS 150,燃燒與連鎖雷擊破也算),通關再依評價加發。
  每級體力 +2%、攻擊 +1.5%、無雙回復 +1%,戰鬥中升級即時生效。友軍擊破與主選單背景的演示不給經驗。
- **戰功 26 項**,分戰鬥、戰役、模式、收集四類,可在「戰功」畫面看進度。
- **服裝**(由戰功解鎖):劉備白袍、關羽金甲、張飛黑甲、呂布赤甲。選將畫面按 **C**(手把 △)切換。
- **武器成長**:擊破敵將與呂布必定掉落發光的**武器匣**。每撿一個,武器等級 +1(上限 10,每級攻擊 +6%)並附加屬性,
  武器進度跨場次保留:

| 屬性 | 效果 |
|---|---|
| **炎** | 燃燒 3 秒,每 0.5 秒掉血 |
| **雷** | 18% 機率觸發鏈電,跳到最多 3 名鄰近敵人 |
| **冰** | 減速 40% 共 3 秒,12% 機率直接凍結 |

## 戰鬥

### 鍵盤與滑鼠

| 按鍵 | 動作 |
|---|---|
| `WASD` / 方向鍵 | 移動 |
| `J` / `Z` / 滑鼠左鍵 | 普通攻擊(**六段連擊**) |
| `K` / `X` | **蓄力 C 技**:站立按 = C1,第 N 段後按 = C(N+1),共 C1~C6 |
| `空白鍵` | 跳躍(空中 `J` = 空中連斬,空中 `K` = 下砸衝擊波) |
| `H` / 滑鼠右鍵(按住) | **格擋**:正面減傷 85%;舉盾後 0.15 秒內受擊觸發**完美格擋**(免傷、時停、無雙 +12、下一擊 ×1.5) |
| `L` / 滑鼠中鍵 | **無雙**(計量滿時,連擊中或受擊中都能發動) |
| `R` | 上馬 / 下馬(靠近坐騎時) |
| `Shift` | 疾走 |
| `Q` / `E` | 旋轉視角 |
| `M`・`Esc`・`Tab` | 靜音・暫停・切換難度(選將畫面) |

### C 技(三人語意相同,動作與範圍依武器不同)

| 招 | 觸發 | 效果 |
|---|---|---|
| C1 | 站立按 K | 破防突進,可貫穿盾兵 |
| C2 | 一段後 | **挑空**,接空中連段 |
| C3 | 二段後 | 三連打,最後一擊**暈眩** 2.6 秒 |
| C4 | 三段後 | 大迴旋,範圍擊飛 |
| C5 | 四段後 | 上劈接橫掃 |
| C6 | 五段後 | 大範圍爆發,衝擊波把周圍全部擊飛 |

### 手把(Xbox / PlayStation / XInput,插上即用)

| 按鍵 | 動作 |
|---|---|
| 左搖桿 / 十字鍵 | 移動(**類比**:推越滿跑越快) |
| 右搖桿・`L2` `R2` | 視角 |
| `□`/`X`・`△`/`Y`・`×`/`A`・`○`/`B` | 攻擊・C 技・跳躍・無雙 |
| `R1`/`RB`・`L1`/`LB`・`L3` | 格擋・疾走・上下馬 |
| `Start`・`Select` | 暫停・切換難度(選將畫面) |

### 觸控(手機 / 平板)

左半螢幕拖曳是**浮動虛擬搖桿**,右半空白處拖曳轉視角。按鍵:**攻**(按住連打)、**技**、**跳**、**無雙**、
**擋**(按住)、**馬**,右上 **Ⅱ** 暫停。支援多點觸控,移動和攻擊可以同時進行。出陣時會進入全螢幕、建議橫向,
觸控裝置從中畫質起跳;按鍵大小與透明度可調。

### 騎馬

戰場上有一匹坐騎待命,靠近後按 `R` 上馬。移動速度 12(疾走 16),速度夠快時會**踐踏**沿路敵兵;
`J` 左右交替側劈、`K` 前衝突擊。

### 據點與士氣

汜水關有 3 座營寨、虎牢關有 4 個據點,開場全為董卓軍所有。每座據點有**守軍**(預設 40),
在據點附近擊破敵兵會削減守軍(雜兵 1、敵將 6),歸零即攻陷:旗幟改換,且不會被奪回。
佔有據點數決定**士氣**(0 座 → 38,全佔 → 90)。士氣低時敵兵生成更多;士氣高時,背景大軍的戰線會明顯往城門推進。

### 敵人與戰場事件

- **刀兵 / 槍兵**:基本雜兵,輪流進攻
- **弓兵**(12 擊破後登場):保持距離射擊,前方有自己人擋著時不放箭
- **盾兵**(20 擊破後登場):正面 120° 擋下普通攻擊,需要用 C 技、無雙或繞到背後
- **騎兵突擊**:地面出現紅色路徑預警,接著騎兵沿線衝鋒,路上的人全部撞飛
- **箭雨**與**敵軍包抄**:由導演壓力系統依戰況觸發。你連擊高、擊殺快時加壓,血量低於三成時放緩 8 秒

敵兵會掉落**肉包子**(回體力)與**酒**(回無雙)。擊破敵將時有慢鏡環繞運鏡;
連擊 10/30/60/120 顯示稱號,擊破數 50/100/200/300/500/1000 彈出獎章。

## 引導與演出

- **戰前簡報**:史實背景、主要 / 次要目標,以及俯視地圖(城門、據點、董卓逃跑路線、我軍位置)。
  快速出陣與重新出陣會跳過。
- **情境式教學**:第一次遊玩時一次提示一個操作(移動 → 連擊 → C 技 → 格擋 → 無雙 → 據點 → 敵將 → 上馬 → 跳躍),
  文字依鍵盤 / 手把 / 觸控顯示,做出動作就關閉。可在設定關閉或重新顯示。
- **對白**:積木臉頭像加台詞,在開場、敵將登場與被擊破、BOSS 登場、友軍倒地、危急、勝利、董卓接近北門時出現。
- **每關配樂**:汜水關明亮的 104 BPM、虎牢關 96 BPM、洛陽急促的 118 BPM 追擊鼓點。
- **戰績分享卡**(結算畫面按 `S`):用當下戰場畫面合成 1200×630 的戰績卡(頭像、模式、評價、擊破、連擊、用時)。
  可以分享(手機 Web Share)、複製圖片、下載,或複製一行文字戰績(附遊戲連結)。

## 線上排行榜與數據

- **榜單**:每日挑戰(每天一張)、無盡之陣(先比波數再比擊破)、三關 × 三難度。
  **只有在結算畫面按「登錄排行榜」才會送出**。同一台裝置每張榜只保留最佳成績,改暱稱會一起搬過去。
- **伺服器檢查**:用時 15~3600 秒、擊破數 / 連擊 / 波數與時間的比例上限、每 IP 每分鐘最多 12 次。
  網頁遊戲無法做到完全防作弊,這裡只擋明顯不可能的成績。
- **自製埋點**:不載入任何第三方 script、不存個人資料,伺服器只保留每日加總:開局數、勝敗與用時、
  敗北時間點、評價、無盡之陣波數、中途離開、語言與裝置類型。
- **後端**:`api/score.js`、`api/event.js`、`api/stats.js`(Vercel Functions)加 Upstash Redis。
  **沒有資料庫時**,API 回 `503 {enabled:false}`:遊戲內排行榜顯示「尚未開放」、結算頁不顯示登錄列,其他功能不受影響。
- **開通步驟**:Vercel 專案 → Storage / Marketplace → 加入 **Upstash Redis** 並連到專案
  (會自動注入 `KV_REST_API_URL` / `KV_REST_API_TOKEN`)→ 重新部署。要看數據就再設 `STATS_TOKEN`,
  打開 `/api/stats?days=7&token=…`,可看到各關各難度的場次、勝率、平均通關時間與中途離開數。
- **本機測試**:`.claude/serve.mjs` 內建記憶體版 Redis 模擬,`/api/*` 在本機可直接用。
  `POST /__mock?on=0` 模擬未開通,`?reset=1` 清空資料。

## 設定與語言

預設英文,可在設定中切換成繁體中文,即時生效不需重新整理。舊版存檔會在改版後切成英文一次,之後選擇中文會被記住。
武將名、稱號、武器、敵將、據點、難度、屬性、連擊稱號與獎章全部都有英文版。

設定項目(存在 `localStorage`):主音量 / 背景音樂 / 音效・畫質(依 FPS 自動 / 高 / 中 / 低)・
視角靈敏度與反轉・畫面震動 0~150%・手把震動與死區・傷害數字・教學提示・
觸控按鍵(自動 / 開 / 關)、大小與透明度・清除存檔。

## 自我測試

在網址後面加 **`?selftest`**(例:<https://brick.akiraxclaw.com/?selftest>),或在主控台執行 `await GAME.selftest()`。
頁面會用 `tick()` 快轉跑完 **31 項情境**,約 15~20 秒:

- **系統**:主選單演示、進入戰鬥後不殘留輸入、各武將開局、各無雙、無盡之陣、每日挑戰、暫停 → 設定存檔、
  語言切換、觸控、手把、主控台無錯誤
- **成長與收集**:呂布未解鎖 → 擊破後解鎖 → 單騎出陣與天下無雙;等級與存檔;戰功與服裝;撿武器匣不會洗掉等級加成
- **引導與演出**:對白順序與配樂切換、戰前簡報、情境式教學
- **關卡流程**:虎牢關目標與城門;汜水關攻陷營寨 → 華雄出關 → 60 秒限時(含失敗);敵將招牌技;
  洛陽出逃 → 追上 → 徐榮斷後 → 擊破;董卓逃脫即敗北;燃燒瓦礫;戰役地圖 → 紀錄 → 下一戰;勝利結算與分享卡;敗北
- **線上**:偵測排行榜是否開通、登錄列顯示與否、輸入暱稱不觸發遊戲按鍵、排行榜畫面切換、伺服器拒絕不可能的成績。
  本機(模擬資料庫)另外實測登錄、改名、讀回與埋點統計;正式站只做唯讀檢查,不會寫入排行榜。
- **平衡回歸**:以模擬玩家(只用真實輸入)驗證「60 秒內必定攻陷營寨」與「普通難度追得上董卓」。
  這兩項都抓到過真實的卡關 bug。

每個測試使用固定亂數種子,跑完會還原 `localStorage`(`musou.*`)、設定、語言與手把。
測試套件經過「故意弄壞遊戲再跑」驗證,確認真的會失敗。`GAME.selftest({only:'無雙'})` 只跑名稱含關鍵字的項目。

## 技術備註

- **資料驅動關卡**:`STAGES.<id>` 描述競技場、出生點、敵將與 BOSS 登場時機、據點、背景軍團、兵種出現時機、
  事件、任務目標、天色與場景建造函式。`loadStage()` 拆掉舊世界(只釋放非快取的 GPU 資源)後重建。
  把原本寫死的虎牢關搬進來時,用 17 項結構指紋比對,零差異。
- **任務目標 `OBJ`**:defeat / capture / kills,支援 `after`、`within`(以遊戲內時間計,慢動作與運鏡不吃玩家時間)、
  `optional`、`final` 與自訂失敗條件。
- **佈景工具組 `propKit`**:地面、可開啟鉸鏈城門的關城、峽谷岩壁、階梯積木山、可燃燒的房屋、旗幟、火盆、營帳、
  拒馬、箭樓。方塊依顏色合併網格,一整排山只佔少數 draw call。
- **統一輸入層**:`input.keys` 是 Proxy,讀取時取「鍵盤 ∪ 手把」。手把、觸控與主選單 bot 都合成同樣的鍵碼與類比軸,
  所以加入它們時戰鬥程式一行都沒改。
- **i18n**:`I18N.zh` / `I18N.en` 加上 `T(key, …args)`;資料表各自掛 `en:{…}`,由 `LN(obj, field)` 取用;
  靜態 DOM 用 `data-t` / `data-th` / `data-tp` 標記。
- **兵海渲染**:背景軍團(4 個 InstancedMesh × 200)、互動雜兵(依效能檔上限 60 / 100 / 140)、InstancedMesh 屍體池。
  每名雜兵每個關節底下的零件以頂點色烘焙合併成單一 mesh(21 → 10 draw calls),160 名雜兵每幀約 4.6ms。
- **武將建模**:頭、軀幹、手臂、腿是 LDraw 零件;盔甲、臉、披風的印刷在載入時用 canvas 畫上去,頭飾、鬍子、肩甲由程式雕塑。
  每位武將、敵將與董卓是 `V2` 表的一筆設定,同一關節底下的靜態零件會合併。雜兵刻意統一成低彩度的敵軍色,讓武將在兵海裡跳出來。
  網址加 **`?v1`** 可切回舊的素色模型。
  觸控裝置的印刷貼圖用半解析度(貼圖記憶體只要四分之一,手機螢幕上看不出差別);本關的敵將與 BOSS 會在開場卡期間先建好,
  登場時不會頓一下。
- **兵海密度**:敵兵以玩家為中心在 13~23 碼的環上生成,而不是固定從城門出來;離得遠的會加速趕上、落隊的會被回收、
  圍在你的攻擊範圍內遊走。壓力系統只限制「同時進攻人數」,不減少在場人數。
- **效能自適應**:`PERF` 以遲滯切換三檔(bloom、陰影、pixelRatio、敵量上限、軍團規模)。
- **渲染**:EffectComposer + UnrealBloomPass(HDR 閾值高於 1.0,只有特效會發光)、ACES Filmic、4× MSAA half-float;
  披風與戰裙用 verlet 布料模擬;全部音樂音效以 Web Audio 即時合成。
- **分享卡取像**:renderer 沒開 `preserveDrawingBuffer`,結算時在同一個 task 內先渲染再 `drawImage`,戰鬥中不必為截圖付出效能代價。

### 除錯主控台

```js
GAME.step(5)                   // 快轉 5 秒(GAME.step(5,{render:false}) 不渲染)
GAME.PERF.force(0)             // 強制最低效能檔
GAME.setDiff('shura')          // 切換難度
GAME.cavalry(); GAME.arrowRain(); GAME.flank()   // 手動觸發事件
GAME.director.P                // 目前壓力值
GAME.spawnDrop(GAME.player.pos,'wbox','fire')    // 生成炎屬性武器匣
GAME.bases; GAME.morale.v; GAME.MOUNT            // 據點、士氣、坐騎狀態
```
